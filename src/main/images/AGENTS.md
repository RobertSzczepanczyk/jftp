# Application images

- Preserve classpath package-relative paths, filenames, expected image formats/sizes, packaging, and UI references. Image filenames alone do not identify their use; check code and resource references before moving or replacing an asset.
- When assets or packaging change, keep the inventory in [review-security-assets.md](../../../docs/review-security-assets.md), resource references in [resources-and-help.md](../../../docs/resources-and-help.md), and root/scoped guidance current. The existing inventory is path/type/size metadata only; verify appearance when image content or rendering changes.
